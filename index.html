Как установить

  1. Скачайте лаунчер

    Файл TimurSimulator.exe по кнопке выше. Положите его куда удобно, например на рабочий стол.

  2. Запустите его

    Windows может показать окно «Windows защитила ваш компьютер». Нажмите «Подробнее», затем «Выполнить в любом случае».

  3. Дождитесь загрузки игры

    При первом запуске лаунчер скачает игру. Когда полоса заполнится, нажмите «Играть».

Обновления приходят сами

Запускайте игру через лаунчер. Он проверит новую версию, скачает её и только потом даст нажать «Играть».

Где лежит игра

В папке %LOCALAPPDATA%\TimurSimulator. Вставьте этот путь в адресную строку Проводника, чтобы открыть её.

Как удалить

Удалите папку %LOCALAPPDATA%\TimurSimulator и сам файл TimurSimulator.exe. Больше игра ничего на компьютере не оставляет.
